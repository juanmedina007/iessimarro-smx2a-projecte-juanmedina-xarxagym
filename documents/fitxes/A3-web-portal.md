# Fitxa d'activitat A3 · Web: Desplegament del portal web corporatiu XarxaGym

- **Codi i nom:** A3 - Desplegament del portal web corporatiu XarxaGym
- **Incidència vinculada:** #13
- **Fita:** M0 Planificació
- **Rol assignat:** Rol C
- **Mòduls i RA implicats:** MP08 (RA1, RA2), MP07 (RA3)
- **Durada estimada:** 10 hores (Setmana S3)

## Descripció de l'activitat
Instal·lar i configurar el servidor web (Apache/Nginx) per servir el portal informatiu de XarxaGym amb informació del centre, horaris, tarifes i contacte, comprovant l'accés des dels equips de la xarxa interna.

## Entregables i evidències
- Contingut del lloc web i configuració del *virtual host* a proves/.
- Captures del portal carregat correctament al navegador i respostes HTTP a evidencies/.

## Instrument d'avaluació (100 %)

| Criteri d'avaluació | Pes | Evidència comprovable |
|---|---|---|
| Servidor web instal·lat, actiu i sense errors de configuració | 25 % | Estat del servei web i comprovació de sintaxi |
| Contingut informatiu de XarxaGym complet i ben estructurat | 30 % | Pàgines visibles amb dades del gimnàs, horaris i serveis |
| Accés per nom de domini intern i codis d'estat HTTP correctes (200) | 25 % | Captura d'accés des d'un equip client i capçaleres HTTP |
| Documentació tècnica i seguiment en GitHub | 20 % | Fitxa completa i commits amb Refs #13 |
