# Xarxa i Serveis per a Centre de Fitness Projecte Intermodular SMX

Aquest projecte té com a objectiu dissenyar i implementar la infraestructura de xarxa, el servidos DHCP/DNS i les polítiques de seguretat per a modernitzar els serveis informàtics d'un centre de fitness (xarxagym).

## Autor
Juan Medina (@juanmedina007)

## Rols simulats
Rol A - Coordinació general, documentació del repte i gestió del repositori.
Rol B - Disseny de la xarxa, adreçament IP i configuració del cablejat.
Rol C - Configuració de serveis (DHCP/DNS) i polítiques de seguretat i còpies de seguretat.

## Contingut del repositori
documents/ Document de Repte (Annex A)
documents/fitxes/ fitxes d'activitat (Annex B)
configuracio/ configuracions tècniques (quan s'execute el projecte)
